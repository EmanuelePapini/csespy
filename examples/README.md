# Examples

Small, self-contained scripts showing how to use **CSESpy** and reproducing the code used in the paper appendix.  
Run from this folder (or repo root) with:

    python example_<name>.py

## Scripts

- **example_multipayload_quick.py** — Fig. 9: multi-payload quicklook (storm vs quiet semi-orbits).
- **example_multipayload_storm2021.py** — Fig. 11: Oct 2021 storm/SEP event, multi-payload timeseries (+ simple latitude selection).
- **example_orbitdb.py** — Fig. 7: orbit database usage and orbit coverage / revisit pattern plots.

## Notes

- Edit the top “USER SETTINGS” section inside each script if you need to point to your local data/orbitdb paths.
- Examples are intentionally minimal and commented so they can be reused/adapted quickly.
